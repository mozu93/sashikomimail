# 差し込みメール送信 — 社内利用手順

## 初回設定

1. 「設定」タブへテナントIDとクライアントIDを入力する
2. 必要に応じて代理差出人とテスト送信先を入力する
3. Gmailからも送信する場合は「Gmail（SMTP）での送信」欄へGmailアドレス、
   アプリパスワード、テスト送信先を入力し、「接続テスト」で確認する
4. 「設定を保存」を押す
5. 「サインイン／確認」を押し、送信に使用するMicrosoft 365アカウントを確認する

共有メールボックスを代理差出人にする場合、認証アカウントへMicrosoft 365側で
「メールボックス所有者として送信」権限が必要です。

代理差出人を使用すると、配信不能通知（NDR）と返信は代理差出人のアドレスへ
届きます。送信後は代理差出人の受信トレイも確認してください。

## 送信手順

1. ExcelまたはCSVを読み込むか、保存済み名簿を開く
2. To列を選択し、必要に応じて固定CC・固定BCCを設定する
   （固定CC・固定BCC欄の「連絡先」ボタンから、「連絡先」タブに
   登録済みの相手を選んで追記できる）
3. エラー行がある場合は内容を確認し、業務上問題がない行だけ
   「選択行のエラーを確認・有効化」から有効化する
4. 送信対象から外したい行があれば、一番左の「状態（送信対象）」列の
   チェックを外す（表示は残るが送信対象からのみ除外される）
5. 差出人で「自分のアドレス」「代理差出人」「Gmail」から選択する
   （Gmailを選ぶとGmailのSMTPで送信し、添付の安全上限も25MBへ切り替わる）
6. 件名、本文、署名を設定する
7. 必要に応じて共通添付・個別添付・検索/絞り込みを設定する
8. 選択行をプレビューする
9. テスト送信を実行し、宛先・本文・添付を確認する
10. 表示されている送信対象件数を確認して一括送信する
11. 「宛先の注意点を確認」が出た場合、打ち間違いドメインと携帯キャリア宛の
    件数を確認する

送信中は誤操作防止のため、編集操作と他タブがロックされます。ロック中のボタンは
グレーで表示されます。進捗バーの上に、処理中の宛先アドレスと添付ファイル名が
1件ずつ表示されます。

エラー行の行番号は絞り込みの有無にかかわらずExcel / CSVの実際の行番号です。
有効化した行は絞り込み条件を変えても確認済みのまま保たれます。検索・絞り込みが
有効な間は、件数表示の下に「絞り込み中: ...」「検索中: ...」と条件が常に
表示されるため、絞り込んだままになっていることに気づきやすくなっています。

ボタンがグレーでないのに押しても反応しない場合は、常に最前面表示の別アプリ
（通知ツールなど）がボタンに重なっていないか確認してください。ウィンドウを
画面中央寄りへ移動すると解消します。

作成・送信タブのプルダウン（To列、差出人、テンプレート、署名）は、
マウスホイールでは切り替わりません。プルダウンの上でホイールを回すと画面が
スクロールします。選択を変えるときはクリックして一覧から選んでください。

## 「受理」の扱い

送信結果と送信履歴の「受理」は、Microsoft 365が送信要求を受け付けた件数です。
相手への到達を保証するものではありません。「届かない」と連絡があった場合は、
次を確認してください。

1. 相手の迷惑メールフォルダ
2. 携帯キャリアの指定受信設定（なりすまし規制で通知なく破棄されます）
3. 代理差出人アドレスに届く配信不能通知
4. 名簿のアドレスの打ち間違い

原因が特定できない場合は、送信日時・件名・宛先を添えて管理担当者へ
メッセージ追跡を依頼してください。

## 中断・エラー後の再送

1. 「送信履歴」タブで対象履歴を選択する
2. 下段の明細で「エラー」「未送信」を確認する
3. 「エラー・未送信を再送」を押す
4. 件数を確認して再送する

履歴一覧は上段の検索欄、選択した履歴の宛先などの明細は下段の検索欄で
それぞれ絞り込めます。ひらがな／カタカナ、全角／半角の違いは区別しません。

受理済みの宛先は再送対象になりません。添付ファイルが移動・削除されている場合、
再送できないため、元の場所へ戻してから操作してください。

## よく使うCC・BCC先の登録

上司・部下など、送信のたびによく使う相手は「連絡先」タブに名前と
メールアドレスを登録しておくと、送信手順2の「連絡先」ボタンから
チェックボックスで選んで固定CC・固定BCCに追記できます。「Excelから
インポート」から、Excel / CSVの任意の列を「名前」「メールアドレス」として
選び、まとめて登録することもできます。

## データ保護とバックアップ

- 保存名簿、送信対象、宛先、件名、エラー内容、連絡先のメールアドレスは
  Windows DPAPIで暗号化される
- データは `%APPDATA%\SashikomiMail\sashikomi_mail.db` に保存される
- 「設定」タブの「データをバックアップ」から定期的にコピーを保存する
- バックアップは暗号化したWindowsユーザーとPCでの復元を前提とする
- 送信履歴は初期設定で365日保存される
- 不要な履歴は「送信履歴」タブから削除できる

## 障害時

予期しないエラーは次へ記録されます。

```text
%APPDATA%\SashikomiMail\sashikomi_mail.log
```

問い合わせ時は、操作内容、発生時刻、画面のエラー、ログファイルを管理担当者へ
連絡してください。ログやデータベースには個人情報が含まれる可能性があるため、
社外へ送らないでください。

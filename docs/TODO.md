## 4. 既知の制限・今後の候補

- 列の削除・列名の変更は未対応（追加のみ）
- Excel貼り付けで、セル内に改行や引用符があるデータは未対応
- 名簿一覧は、開くたびに全名簿の全行を復号して読み込む。数百件・数万行規模では遅くなる可能性がある（行データと分けて件数を持たせるにはDBスキーマの変更が必要）
- 新機能のGUI部分は、一時スクリプトでの検証のみで、自動テストは未追加（純粋関数のテストは追加済み）

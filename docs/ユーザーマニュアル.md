# 差し込みメール送信 ユーザーマニュアル

## アップデート

アプリ起動時に新しい正式版が見つかると、画面上部に通知が表示されます。
「ダウンロード」を押し、完了後に「今すぐ更新」を押してください。アプリが
いったん終了し、更新後に自動で再起動します。送信中は更新操作を行わないで
ください。更新確認に失敗した場合も、メール作成・送信機能は通常どおり使えます。

対象バージョン：1.1.5

## 1. アプリの目的

ExcelまたはCSVに記載された宛先・氏名・事業所名などを使用し、宛先ごとに内容を
差し込んだメールをMicrosoft 365から個別送信するWindowsアプリです。

## 2. 起動

インストール済みの場合は、デスクトップまたはスタートメニューの
「差し込みメール送信」を開きます。配布フォルダ版では
`SashikomiMail.exe`を実行します。

画面上部には次のタブがあります。

- 作成・送信
- テンプレート
- 署名
- 送信履歴
- 設定

## 3. 初回設定

1. 「設定」タブを開く
2. 管理者から案内されたテナントIDとクライアントIDを入力
3. 必要に応じて代理差出人とテスト送信先を入力
4. 「設定を保存」を押す
5. 「サインイン／確認」を押す
6. Microsoft 365へサインインし、表示された送信アカウントを確認

一括送信は送信アカウントを確認するまで実行できません。

代理差出人を設定した場合、配信不能通知（NDR）と受信者からの返信は、
サインインしたアカウントではなく代理差出人のアドレスへ届きます。
不達を見落とさないよう、代理差出人の受信トレイも定期的に確認してください。

## 4. 宛先データの準備

対応形式は`.xlsx`、`.xls`、`.csv`です。1行目をヘッダーとして扱います。

例：

| 事業所名 | 氏名 | 氏名2 | メールアドレス | 代理メール |
|---|---|---|---|---|
| 山田商事 | 山田太郎 |  | taro@example.jp | office@example.jp |

セル結合や複数段ヘッダーは避けてください。Excelは先頭シートを読み込みます。

## 5. 名簿を読み込む

1. 「作成・送信」タブを開く
2. 「Excel / CSVを選択」を押す
3. ファイルを選択
4. データプレビューの件数とエラーを確認
5. 継続利用する場合は「現在の名簿を保存」を押す

宛先の重複などで「エラー」と表示された行は、行を選択して
「選択行のエラーを確認・有効化」を押すと、エラー内容と行データを確認できます。
内容に問題がないと判断して有効化した行は「確認済み」と表示され、送信対象になります。
行データを編集した場合やTo列・CC列を変更した場合は確認済み状態が解除されるため、
もう一度内容を確認してください。

保存済み名簿は「保存済み名簿を開く」から再利用できます。不要な名簿は
「保存済み名簿を削除」から削除します。

## 6. データを絞り込む

データプレビュー上部で、対象列と条件を選択します。

- 含む
- 完全一致
- 空欄
- 空欄でない

「表示・送信対象」の件数に含まれる行だけが一括送信されます。「解除」で全件へ
戻ります。

## 7. 宛先を設定する

- To列：必須。メールアドレスが入った列を選択
- CC列：任意。行ごとに異なるCCを指定
- 固定BCC：任意。すべてのメールへ同じBCCを追加

複数アドレスはカンマ、セミコロン、改行で区切ります。

作成・送信タブのプルダウン（To列、CC列、差出人、テンプレート、署名）は、
マウスホイールでは切り替わりません。誤って選択が変わることを防ぐためです。
プルダウンの上でホイールを回した場合は、画面がスクロールします。
選択を変更するときは、プルダウンをクリックして一覧から選んでください。

## 8. 件名と本文を作成する

利用可能タグをダブルクリックすると本文へ挿入できます。

```text
{事業所名}

{氏名| 様}
```

通常タグ：

```text
{氏名}
```

条件付きタグ：

```text
{氏名2| 様}
```

条件付きタグは値がある場合だけ「値＋後置文字」を表示します。氏名2が空欄なら
「様」も表示されません。

入力中の件名と本文は「現在の件名・本文をテンプレート登録」から保存できます。

## 9. 署名

1. 「署名」タブを開く
2. 「新しい署名」を押す
3. 署名名と署名本文を入力
4. 「署名を保存」を押す
5. 「作成・送信」タブで使用する署名を選択

署名は送信時に本文末尾へ追加されます。

## 10. 添付ファイル

### 共通添付

「ファイルを追加」から、全宛先へ同じファイルを添付します。

### 個別添付

1. 「個別添付フォルダを選択」を押す
2. ファイル名と照合する1項目目の列を選択
3. 2項目目の列を選択
4. 個別ファイルが入ったフォルダを選択
5. 割当一覧と未一致ファイルを確認

`NO.`が`12`、事業所名が`山田商事`の場合、次が一致します。

```text
12_山田商事.pdf
12_山田商事_請求書.pdf
12_山田商事-案内.pdf
```

個別添付がない送信対象がある場合は送信前に警告します。一括送信の最終確認には
割当済み件数を表示し、個々のファイル名は「選択行をプレビュー」でも確認できます。

共通添付と個別添付の合計は1通あたり2.5MBまでです。

## 11. プレビューとテスト送信

1. データプレビューで確認する行を選択
2. 「選択行をプレビュー」を押す
3. To、CC、BCC、件名、本文、添付を確認
4. 「テスト送信」を押す
5. テスト送信先で受信内容を確認

テスト送信は送信履歴へ「テスト」として保存されます。

## 12. 一括送信

1. 表示・送信対象件数を確認
2. 宛先設定の「差出人」で「自分のアドレス」または登録済みの「代理差出人」を選択
3. 「一括送信」を押す
4. 「宛先の注意点を確認」が表示された場合は内容を確認
5. 認証アカウント、差出人、件数を確認
6. 最終確認で「はい」を選択

ここで選択した差出人は、テスト送信と送信履歴からの再送にも使用されます。
代理差出人が設定されていない場合は「自分のアドレス」だけが表示されます。

### 宛先の注意点を確認

次のどちらかに該当する宛先があると、送信前に確認画面が表示されます。
「いいえ」を選ぶと送信準備を中止し、名簿を修正できます。

**打ち間違いが疑われるドメイン**

`dokomo.ne.jp`（正しくは`docomo.ne.jp`）のように、実在するドメインと
1文字違いのアドレスを検出します。この種のドメインは第三者が実際に
取得・運用している場合があり、誤って送信しても配信不能通知が返りません。
添付ファイルを含めて他人に届いたままになるため、必ず名簿を修正してください。

**携帯キャリア宛**

`docomo.ne.jp`、`ezweb.ne.jp`、`i.softbank.jp`などの件数を集計して表示します。
これらの回線では「なりすまし規制」「パソコンメール拒否」が有効な場合があり、
送信側にエラーが返らないまま破棄されることがあります。事前に送信元ドメインの
指定受信設定を案内してください。

### 送信中の表示

送信中は、進捗バーの上に処理中の宛先アドレスと添付ファイル名が1件ずつ
表示されます。

```text
3/69件目を送信中　宛先: taro@example.jp　／　添付: 12_山田商事.pdf
```

添付が割り当てられていない宛先は「添付: なし」と表示されるため、
個別添付の割当漏れをその場で確認できます。

送信中は編集操作と他タブがロックされます。「送信を中止」で、現在処理中の
メールが完了した後に中断します。

### 「受理」の意味

送信完了後に表示される「送信要求の受理」は、Microsoft 365が送信要求を
受け付けた件数です。**相手に届いたことを保証するものではありません。**
受信側の迷惑メール判定や携帯キャリアの規制では、送信側にエラーが返らないまま
破棄される場合があります。

宛先ごとの実際の配信結果を確認するには、管理担当者へ連絡し、Microsoft 365の
メッセージ追跡で調査を依頼してください。

## 13. 送信履歴と再送

「送信履歴」タブで、テスト・一括・再送の結果を確認できます。上段で履歴を選ぶと、
下段に宛先ごとの受理・エラー・未送信が表示されます。「受理」は送信要求が
受け付けられた状態で、到達を保証するものではありません。

エラー・未送信だけを再送する場合：

1. 対象履歴を選択
2. 「エラー・未送信を再送」を押す
3. 件数を確認して再送

受理済みの宛先は再送されません。添付元ファイルが移動・削除されている場合は
再送できません。

## 14. 「届かない」と言われたとき

送信履歴が「受理」でも相手に届かない場合があります。次の順に確認してください。

1. 相手に迷惑メールフォルダを確認してもらう（Gmail、iCloud、Outlookなど）
2. 携帯キャリアの場合、送信元ドメインを指定受信に追加してもらう
3. 代理差出人のアドレスに配信不能通知（NDR）が届いていないか確認する
4. 名簿のアドレスに打ち間違いがないか確認する
   （`dokomo.ne.jp`のように実在する誤記ドメインは通知が返りません）
5. それでも原因が分からない場合は、送信日時・件名・宛先を添えて
   管理担当者へメッセージ追跡を依頼する

## 15. バックアップ

「設定」タブの「データをバックアップ」を押し、`.db`ファイルを安全な場所へ
保存します。バックアップには個人情報が含まれるため、アクセス制限された
社内保管場所を使用してください。

## 16. エラー発生時

画面に表示されたエラー内容、発生時刻、実行した操作を管理担当者へ連絡します。
障害ログは次へ保存されます。

```text
%APPDATA%\SashikomiMail\sashikomi_mail.log
```

ログやデータベースを社外へ送らないでください。

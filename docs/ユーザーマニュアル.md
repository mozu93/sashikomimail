# 差し込みメール送信 ユーザーマニュアル

## アップデート

アプリ起動時に新しい正式版が見つかると、画面上部に通知が表示されます。
「ダウンロード」を押し、完了後に「今すぐ更新」を押してください。アプリが
いったん終了し、更新後に自動で再起動します。送信中は更新操作を行わないで
ください。更新確認に失敗した場合も、メール作成・送信機能は通常どおり使えます。

対象バージョン：1.3.3

## 1. アプリの目的

ExcelまたはCSVに記載された宛先・氏名・事業所名などを使用し、宛先ごとに内容を
差し込んだメールをMicrosoft 365またはGmailから個別送信するWindowsアプリです。

## 2. 起動

インストール済みの場合は、デスクトップまたはスタートメニューの
「差し込みメール送信」を開きます。配布フォルダ版では
`SashikomiMail.exe`を実行します。

画面上部には次のタブがあります。

- 作成・送信
- テンプレート
- 署名
- 連絡先
- 送信履歴
- 設定

## 3. 初回設定

1. 「設定」タブを開く
2. 管理者から案内されたテナントIDとクライアントIDを入力
3. 必要に応じて代理差出人とテスト送信先を入力
4. 「設定を保存」を押す
5. 「サインイン／確認」を押す
6. Microsoft 365へサインインし、表示された送信アカウントを確認

一括送信は送信アカウントを確認するまで実行できません。

Gmailからも送信する場合は、「Gmail（SMTP）での送信」欄にGmailアドレス、
アプリパスワード、テスト送信先を入力し、「接続テスト」で確認してから
「設定を保存」を押します。アプリパスワードはGoogleアカウントの2段階認証を
有効にしたうえで発行してください（通常のGoogleパスワードでは接続できません）。

代理差出人を設定した場合、配信不能通知（NDR）と受信者からの返信は、
サインインしたアカウントではなく代理差出人のアドレスへ届きます。
不達を見落とさないよう、代理差出人の受信トレイも定期的に確認してください。

## 4. 宛先データの準備

対応形式は`.xlsx`、`.xls`、`.csv`です。1行目をヘッダーとして扱います。

例：

| 事業所名 | 氏名 | 氏名2 | メールアドレス | 代理メール |
|---|---|---|---|---|
| 山田商事 | 山田太郎 |  | taro@example.jp | office@example.jp |

セル結合や複数段ヘッダーは避けてください。Excelは先頭シートを読み込みます。

## 5. 名簿を読み込む

1. 「作成・送信」タブを開く
2. 「Excel / CSVを選択」を押す
3. ファイルを選択
4. データプレビューの件数とエラーを確認
5. 継続利用する場合は「現在の名簿を保存」を押す

宛先の重複などで「エラー」と表示された行は、行を選択して
「選択行のエラーを確認・有効化」を押すと、エラー内容と行データを確認できます。
内容に問題がないと判断して有効化した行は「確認済み」と表示され、送信対象になります。
行データを編集した場合やTo列を変更した場合は確認済み状態が解除されるため、
もう一度内容を確認してください。

保存済み名簿は「保存済み名簿を開く」から再利用できます。不要な名簿は
「保存済み名簿を削除」から削除します。

データプレビューでセルを編集したり行を削除したりした内容は、「Excelとして
出力」から新しいExcelファイル（.xlsx）として書き出せます。このアプリ専用の
保存（暗号化されたデータベース）とは別に、他のアプリや他の人とデータを
共有したいときに使えます。送信対象チェックの状態は出力に含まれません。

データプレビュー表の一番左「状態（送信対象）」列のチェックを外すと、
その行は表示されたまま送信対象からだけ除外できます。見出しをクリックすると
全行のチェックを一括でON/OFF切り替えできます。チェック状態は名簿の保存・
再読み込みには保持されず、開き直すたびに全行チェック済みに戻ります。

## 6. データを検索・絞り込む

データプレビュー上部の「検索」欄では、全列から入力した文字を含む行を
即座に絞り込みます。「絞り込み」欄では、列を選び「含む」「完全一致」
「空欄」「空欄でない」の条件で絞り込みます。両方の入力欄には×クリア
ボタンがあり、絞り込み欄の文字を消すと（×でも手入力の全消去でも）
絞り込みが自動的に解除されます。

検索・絞り込みが有効な間は、件数表示の下に「絞り込み中: ...」
「検索中: ...」と条件が常に表示されるため、絞り込んだままになっている
ことに気づきやすくなっています。件数表示は「表示 X件 / 送信対象 Y件 /
全Z件」の形式で、検索・絞り込みと送信対象チェックの両方を反映します。

エラー内容に表示される行番号は、絞り込みの有無にかかわらずExcel / CSVの実際の
行番号です。「選択行のエラーを確認・有効化」で有効化した行は、絞り込み条件を
変更しても確認済みのまま保たれます。

## 7. 宛先を設定する

- To列：必須。メールアドレスが入った列を選択
- 固定CC：任意。すべてのメールへ同じCCを追加
- 固定BCC：任意。すべてのメールへ同じBCCを追加

複数アドレスはカンマ、セミコロン、改行で区切ります。固定CC・固定BCCの
入力欄にある「連絡先」ボタンから、「連絡先」タブに登録した相手を
チェックボックスで選んで追記できます（詳しくは「9. 連絡先」を参照）。

作成・送信タブのプルダウン（To列、差出人、テンプレート、署名）は、
マウスホイールでは切り替わりません。誤って選択が変わることを防ぐためです。
プルダウンの上でホイールを回した場合は、画面がスクロールします。
選択を変更するときは、プルダウンをクリックして一覧から選んでください。

## 8. 件名と本文を作成する

利用可能タグをダブルクリックすると本文へ挿入できます。

```text
{事業所名}

{氏名| 様}
```

通常タグ：

```text
{氏名}
```

条件付きタグ（後置文字のみ）：

```text
{氏名2| 様}
```

条件付きタグは値がある場合だけ「値＋後置文字」を表示します。氏名2が空欄なら
「様」も表示されません。

条件付きタグ（前置文字も指定）：

```text
{、|氏名B|様}
```

前置文字も指定すると、氏名Bが空欄のときは直前の「、」も含めて何も
表示されなくなります（「山田様、佐藤様」の氏名B部分だけを空欄時に丸ごと
消したい場合に使用）。「利用可能タグ」欄の「条件付きタグを挿入」ボタンから、
列・前置文字・後置文字をフォームで選ぶだけで、記法を覚えずに挿入できます。

入力中の件名と本文は「現在の件名・本文をテンプレート登録」から保存できます。
「テンプレート」タブでも、新規のテンプレート名・件名・本文をじっくり
作成・編集できます（一覧から選んで内容を書き換え、「テンプレートを保存」
で更新）。
作成・送信タブを開いた直後は「テンプレートなし」が選ばれます。必要な場合だけ
テンプレートを選択して「読込」を押してください。

## 9. 署名

1. 「署名」タブを開く
2. 「新しい署名」を押す
3. 署名名と署名本文を入力
4. 「署名を保存」を押す
5. 「作成・送信」タブで使用する署名を選択

署名は送信時に本文末尾へ追加されます。

## 10. 連絡先

上司・部下など、送信のたびによく使うCC・BCC先の名前とメールアドレスを
登録しておけます。

1. 「連絡先」タブを開く
2. 「新しい連絡先」を押す
3. 名前とメールアドレスを入力
4. 「連絡先を保存」を押す

「Excelからインポート」を使うと、Excel / CSVの任意の列を「名前」
「メールアドレス」として選び、まとめて連絡先登録できます。既存と同じ
名前があれば、上書き前に確認します。

登録した連絡先は、「作成・送信」タブの固定CC・固定BCC欄にある
「連絡先」ボタンから、チェックボックスで選んで追記できます。

## 11. 添付ファイル

### 共通添付

「ファイルを追加」から、全宛先へ同じファイルを添付します。

### 個別添付

1. 「個別添付フォルダを選択」を押す
2. ファイル名と照合する1項目目の列を選択
3. 2項目目の列を選択
4. 個別ファイルが入ったフォルダを選択
5. 割当一覧と未一致ファイルを確認

`NO.`が`12`、事業所名が`山田商事`の場合、次が一致します。

```text
12_山田商事.pdf
12_山田商事_請求書.pdf
12_山田商事-案内.pdf
```

個別添付がない送信対象がある場合は送信前に警告します。一括送信の最終確認には
割当済み件数を表示し、個々のファイル名は「選択行をプレビュー」でも確認できます。

送信前に内容まで確認したい場合は、宛先の行を選択して「添付内容を確認」を押します。
その宛先に実際に付く共通添付・個別添付が一覧になり、選んだファイルを既定のアプリ
（PDFビューアー、Word、Excelなど）で開けます。

共通添付と個別添付の合計は1通あたり、Microsoft 365で送る場合は2.5MB、
Gmailで送る場合は25MBまでです。上限は「差出人」の選択に合わせて自動的に
切り替わり、添付欄の残量バーにも反映されます。

## 12. プレビューとテスト送信

1. データプレビューで確認する行を選択
2. 「選択行をプレビュー」を押す
3. To、CC、BCC、件名、本文、添付を確認
4. 「テスト送信」を押す
5. テスト送信先で受信内容を確認

テスト送信は送信履歴へ「テスト」として保存されます。

## 13. 一括送信

1. 表示・送信対象件数を確認
2. 宛先設定の「差出人」で「自分のアドレス」「代理差出人」「Gmail」から選択
3. 「一括送信」を押す
4. 「宛先の注意点を確認」が表示された場合は内容を確認
5. 認証アカウント、差出人、件数を確認
6. 最終確認で「はい」を選択

ここで選択した差出人は、テスト送信と送信履歴からの再送にも使用されます。
代理差出人が設定されていない場合は「自分のアドレス」と「Gmail」だけが
表示されます。

### 差出人にGmailを選んだ場合

「Gmail（アドレス）」を選ぶと、Microsoft 365ではなくGmailのSMTPで送信します。
設定タブでGmailアドレスとアプリパスワード（Googleアカウントの2段階認証を
有効にしたうえで発行するもの）を登録してください。未登録のまま送信しようと
すると「Gmail未設定」の警告が表示されます。

テスト送信先も設定タブの「テスト送信先（Gmail）」欄が使われます。
添付ファイルの安全上限は、Microsoft 365が合計2.5MB、Gmailが合計25MBで、
差出人の選択に合わせて自動的に切り替わります。

### 宛先の注意点を確認

次のどちらかに該当する宛先があると、送信前に確認画面が表示されます。
「いいえ」を選ぶと送信準備を中止し、名簿を修正できます。

**打ち間違いが疑われるドメイン**

`dokomo.ne.jp`（正しくは`docomo.ne.jp`）のように、実在するドメインと
1文字違いのアドレスを検出します。この種のドメインは第三者が実際に
取得・運用している場合があり、誤って送信しても配信不能通知が返りません。
添付ファイルを含めて他人に届いたままになるため、必ず名簿を修正してください。

**携帯キャリア宛**

`docomo.ne.jp`、`ezweb.ne.jp`、`i.softbank.jp`などの件数を集計して表示します。
これらの回線では「なりすまし規制」「パソコンメール拒否」が有効な場合があり、
送信側にエラーが返らないまま破棄されることがあります。事前に送信元ドメインの
指定受信設定を案内してください。

### 送信中の表示

送信中は、進捗バーの上に処理中の宛先アドレスと添付ファイル名が1件ずつ
表示されます。

```text
3/69件目を送信中　宛先: taro@example.jp　／　添付: 12_山田商事.pdf
```

添付が割り当てられていない宛先は「添付: なし」と表示されるため、
個別添付の割当漏れをその場で確認できます。

送信中は編集操作と他タブがロックされます。ロック中のボタンはグレーで表示され、
押せない状態であることが見た目で分かります。「送信を中止」で、現在処理中の
メールが完了した後に中断します。

### 「受理」の意味

Microsoft 365で送った場合の「送信要求の受理」は、Microsoft 365が送信要求を
受け付けた件数です。Gmailで送った場合は「Gmailへの送信完了」と表示され、Gmailの
SMTPサーバーがメールを受け付けたことを表します。**いずれも相手に届いたことを保証するものではありません。**
受信側の迷惑メール判定や携帯キャリアの規制では、送信側にエラーが返らないまま
破棄される場合があります。

宛先ごとの実際の配信結果を確認するには、管理担当者へ連絡し、Microsoft 365の
メッセージ追跡で調査を依頼してください。

## 14. 送信履歴と再送

「送信履歴」タブで、テスト・一括・再送の結果を確認できます。上段で履歴を選ぶと、
下段に宛先ごとの受理・エラー・未送信が表示されます。「受理」は送信要求が
受け付けられた状態で、到達を保証するものではありません。
名簿に「事業所名」列がある場合は、宛先とあわせて事業所名も表示されます。
明細を選び「選択したメール内容を確認」を押すと、送信時点の宛先・件名・本文・添付を
確認できます。列幅に収まらない件名などは、セルにマウスを重ねると全体を表示します。
この機能の追加前に保存された履歴は、本文・添付情報を表示できない場合があります。

上段の「送信履歴を検索」では種別・日時・ファイル名・件名・状態を検索できます。
下段の「明細を検索」では、上段で選んだ履歴の事業所名・宛先・件名・結果・
エラー内容を検索できます。いずれも、ひらがな／カタカナ、全角／半角の違いは
区別されません。

エラー・未送信だけを再送する場合：

1. 対象履歴を選択
2. 「エラー・未送信を再送」を押す
3. 件数を確認して再送

受理済みの宛先は再送されません。添付元ファイルが移動・削除されている場合は
再送できません。

## 15. 「届かない」と言われたとき

送信履歴が「受理」でも相手に届かない場合があります。次の順に確認してください。

1. 相手に迷惑メールフォルダを確認してもらう（Gmail、iCloud、Outlookなど）
2. 携帯キャリアの場合、送信元ドメインを指定受信に追加してもらう
3. 代理差出人のアドレスに配信不能通知（NDR）が届いていないか確認する
4. 名簿のアドレスに打ち間違いがないか確認する
   （`dokomo.ne.jp`のように実在する誤記ドメインは通知が返りません）
5. それでも原因が分からない場合は、送信日時・件名・宛先を添えて
   管理担当者へメッセージ追跡を依頼する

## 16. バックアップ

「設定」タブの「データをバックアップ」を押し、`.db`ファイルを安全な場所へ
保存します。バックアップには個人情報が含まれるため、アクセス制限された
社内保管場所を使用してください。

## 17. ボタンを押しても反応しないとき

ボタンがグレーではないのに押しても反応しない場合、常に最前面に表示される
別のアプリ（通知ツール、付箋、ウィジェットなど）が、そのボタンの上に
透明なウィンドウとして重なっている可能性があります。画面右下や右上に
配置されるものが多く、その位置にあるボタンだけが反応しなくなります。

次のいずれかで確認してください。

- 差し込みメール送信のウィンドウを画面の中央寄りへ移動して押し直す
- 常時起動している通知系アプリを終了して押し直す

いずれでも反応しない場合は、次項の手順で管理担当者へ連絡してください。

## 18. エラー発生時

画面に表示されたエラー内容、発生時刻、実行した操作を管理担当者へ連絡します。
障害ログは次へ保存されます。

```text
%APPDATA%\SashikomiMail\sashikomi_mail.log
```

ログやデータベースを社外へ送らないでください。

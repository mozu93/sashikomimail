# 差し込みメール送信 ユーザーマニュアル

対象バージョン：1.0.0

## 1. アプリの目的

ExcelまたはCSVに記載された宛先・氏名・事業所名などを使用し、宛先ごとに内容を
差し込んだメールをMicrosoft 365から個別送信するWindowsアプリです。

## 2. 起動

インストール済みの場合は、デスクトップまたはスタートメニューの
「差し込みメール送信」を開きます。配布フォルダ版では
`SashikomiMail.exe`を実行します。

画面上部には次のタブがあります。

- 作成・送信
- テンプレート
- 署名
- 送信履歴
- 設定

## 3. 初回設定

1. 「設定」タブを開く
2. 管理者から案内されたテナントIDとクライアントIDを入力
3. 必要に応じて代理差出人とテスト送信先を入力
4. 「設定を保存」を押す
5. 「サインイン／確認」を押す
6. Microsoft 365へサインインし、表示された送信アカウントを確認

一括送信は送信アカウントを確認するまで実行できません。

## 4. 宛先データの準備

対応形式は`.xlsx`、`.xls`、`.csv`です。1行目をヘッダーとして扱います。

例：

| 事業所名 | 氏名 | 氏名2 | メールアドレス | 代理メール |
|---|---|---|---|---|
| 山田商事 | 山田太郎 |  | taro@example.jp | office@example.jp |

セル結合や複数段ヘッダーは避けてください。Excelは先頭シートを読み込みます。

## 5. 名簿を読み込む

1. 「作成・送信」タブを開く
2. 「Excel / CSVを選択」を押す
3. ファイルを選択
4. データプレビューの件数とエラーを確認
5. 継続利用する場合は「現在の名簿を保存」を押す

保存済み名簿は「保存済み名簿を開く」から再利用できます。不要な名簿は
「保存済み名簿を削除」から削除します。

## 6. データを絞り込む

データプレビュー上部で、対象列と条件を選択します。

- 含む
- 完全一致
- 空欄
- 空欄でない

「表示・送信対象」の件数に含まれる行だけが一括送信されます。「解除」で全件へ
戻ります。

## 7. 宛先を設定する

- To列：必須。メールアドレスが入った列を選択
- CC列：任意。行ごとに異なるCCを指定
- 固定BCC：任意。すべてのメールへ同じBCCを追加

複数アドレスはカンマ、セミコロン、改行で区切ります。

## 8. 件名と本文を作成する

利用可能タグをダブルクリックすると本文へ挿入できます。

```text
{事業所名}

{氏名| 様}
```

通常タグ：

```text
{氏名}
```

条件付きタグ：

```text
{氏名2| 様}
```

条件付きタグは値がある場合だけ「値＋後置文字」を表示します。氏名2が空欄なら
「様」も表示されません。

入力中の件名と本文は「現在の件名・本文をテンプレート登録」から保存できます。

## 9. 署名

1. 「署名」タブを開く
2. 「新しい署名」を押す
3. 署名名と署名本文を入力
4. 「署名を保存」を押す
5. 「作成・送信」タブで使用する署名を選択

署名は送信時に本文末尾へ追加されます。

## 10. 添付ファイル

### 共通添付

「ファイルを追加」から、全宛先へ同じファイルを添付します。

### 個別添付

1. 「個別添付フォルダを選択」を押す
2. ファイル名と照合する列を選択
3. 個別ファイルが入ったフォルダを選択
4. 割当件数と未一致ファイルを確認

事業所名が`山田商事`の場合、次が一致します。

```text
山田商事.pdf
山田商事_請求書.pdf
山田商事-案内.pdf
```

共通添付と個別添付の合計は1通あたり2.5MBまでです。

## 11. プレビューとテスト送信

1. データプレビューで確認する行を選択
2. 「選択行をプレビュー」を押す
3. To、CC、BCC、件名、本文、添付を確認
4. 「テスト送信」を押す
5. テスト送信先で受信内容を確認

テスト送信は送信履歴へ「テスト」として保存されます。

## 12. 一括送信

1. 表示・送信対象件数を確認
2. 「一括送信」を押す
3. 認証アカウント、差出人、件数を確認
4. 最終確認で「はい」を選択

送信中は編集操作と他タブがロックされます。「送信を中止」で、現在処理中の
メールが完了した後に中断します。

## 13. 送信履歴と再送

「送信履歴」タブで、テスト・一括・再送の結果を確認できます。上段で履歴を選ぶと、
下段に宛先ごとの成功・エラー・未送信が表示されます。

エラー・未送信だけを再送する場合：

1. 対象履歴を選択
2. 「エラー・未送信を再送」を押す
3. 件数を確認して再送

成功済みの宛先は再送されません。添付元ファイルが移動・削除されている場合は
再送できません。

## 14. バックアップ

「設定」タブの「データをバックアップ」を押し、`.db`ファイルを安全な場所へ
保存します。バックアップには個人情報が含まれるため、アクセス制限された
社内保管場所を使用してください。

## 15. エラー発生時

画面に表示されたエラー内容、発生時刻、実行した操作を管理担当者へ連絡します。
障害ログは次へ保存されます。

```text
%APPDATA%\SashikomiMail\sashikomi_mail.log
```

ログやデータベースを社外へ送らないでください。

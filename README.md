# 差し込みメール送信

[![CI](https://github.com/mozu93/sashikomimail/actions/workflows/ci.yml/badge.svg)](https://github.com/mozu93/sashikomimail/actions/workflows/ci.yml)

Windows / Microsoft 365・Gmail対応の差し込みメール送信デスクトップアプリです。

最新バージョン：**1.3.1**

Excel / CSV の任意列を差し込みタグとして使用し、Microsoft 365（Microsoft
Graph API）または Gmail（SMTP）から個別メールを一括送信する Windows
デスクトップアプリです。

## セットアップ

```powershell
python -m pip install -r requirements.txt
python main.py
```

アプリのウィンドウとタスクバーには `assets/icon.ico` が使用されます。
デスクトップショートカットにも同じICOファイルを指定できます。

初回は「設定」タブで Microsoft Entra ID のテナントID、クライアントID、
テスト送信先を保存してください。Entra ID 側ではパブリッククライアントを
有効化し、委任された `Mail.Send` アクセス許可を設定します。

## 基本操作

1. 「作成・送信」で xlsx / xls / csv を読み込む
2. 継続利用する場合は「現在の名簿を保存」でアプリ内へ保存する
3. To列を選び、必要に応じて固定CC・固定BCCを設定する
4. 「差出人」で「自分のアドレス」「代理差出人」「Gmail」から選ぶ
5. `{ヘッダー名}` を使って件名・本文を作る
6. 行を選んでプレビューし、テスト送信する
7. エラーがないこと、または内容を確認して有効化済みであることを確認して一括送信する

差出人の選択は、テスト送信、一括送信、送信履歴からの再送に反映されます。
「Gmail」を選ぶと、Microsoft 365ではなくGmailのSMTPで送信します（設定タブに
Gmailアドレスとアプリパスワードの登録が必要です）。添付の安全上限は
Microsoft 365が2.5MB、Gmailが25MBで、差出人の選択に合わせて切り替わります。
代理差出人を利用する場合は、設定画面へのアドレス登録に加えて、Microsoft 365側の
`Mail.Send.Shared`アクセス許可とメールボックスの送信権限が必要です。

入力中の件名と本文は「現在の件名・本文をテンプレート登録」から名前を付けて
保存できます。同名のテンプレートは確認後に更新されます。「テンプレート」
タブでも、新規のテンプレート名・件名・本文をじっくり作成・編集できます。

値が空欄のときに敬称や区切り文字も表示したくない場合は、条件付きタグを
使用します。例えば `{氏名2| 様}` は、氏名2が「佐藤」なら `佐藤 様`、
空欄なら何も表示しません。`{、|氏名B|様}` のように前置文字も指定すると、
氏名Bが空欄のときは直前の「、」も含めて表示されなくなります。「利用可能
タグ」欄の「条件付きタグを挿入」ボタンから、列・前置文字・後置文字を
選ぶだけで記法を覚えずに挿入できます。

共通添付欄には、選択点数・合計容量・残り容量を表示します。点数そのものに
上限はありませんが、Base64変換後の容量を考慮し、合計2.5MBまでです。上限を超える
ファイルは追加されません。

事業所ごとに異なるファイルを送る場合は「個別添付フォルダを選択」を使用し、
照合する2列とフォルダを指定します。例えば `NO.` が `12`、`事業所名` が
`山田商事` の場合、`12_山田商事.pdf`、`12_山田商事_請求書.pdf` などが
その行だけに添付されます。設定直後に割当一覧を表示し、未割当の送信対象が
ある場合は送信前に警告します。最終確認にも割当件数を表示します。
共通添付と個別添付を合わせて、1通あたり2.5MBまでです。

テンプレート、設定、送信履歴は
`%APPDATA%\SashikomiMail\sashikomi_mail.db` に保存されます。OAuthトークンは
同じフォルダへOS暗号化付きで保存されます。

保存済み名簿は「保存済み名簿を開く」から再利用でき、
「保存済み名簿を削除」から確認後に削除できます。

データプレビューでセルを編集したり行を削除したりした内容は、
「Excelとして出力」から新しいExcelファイル（.xlsx）として書き出せます。
このアプリ専用の保存（暗号化されたデータベース）とは別に、他のアプリや
他の人とデータを共有したいときに使えます。送信対象チェックの状態は
出力に含まれません。

名簿の重複宛先などでエラーになった行は、行を選択して
「選択行のエラーを確認・有効化」を押すと、エラー内容と行データを確認できます。
業務上問題がない場合に限り有効化すると、行は「確認済み」となり送信対象に
含まれます。行データの編集やTo列の変更後は、再確認が必要です。
エラー内容の行番号は絞り込みの有無にかかわらずExcel / CSVの実際の行番号で、
有効化した行は絞り込み条件を変えても確認済みのまま保たれます。

作成・送信タブのプルダウン（To列、差出人、テンプレート、署名）は、
誤操作防止のためマウスホイールでは切り替わりません。プルダウンの上で
ホイールを回した場合は画面がスクロールします。

送信中は進捗バーの上に、その時点で送信している宛先アドレスと添付ファイル名を
表示します。送信中はボタンがグレーになり、操作できない状態が見た目で分かります。
送信前には、打ち間違いが疑われるドメイン（`dokomo.ne.jp` など、
実在するため配信不能通知が返らないもの）と、携帯キャリア宛の件数を確認できます。

テスト送信も送信履歴へ保存されます。履歴の「種別」列で「テスト」と「一括」を
区別でき、受理・エラー・宛先・件名・エラー詳細は再起動後も確認できます。
「受理」はMicrosoft 365が送信要求を受け付けた件数で、相手への到達を
保証するものではありません。受信側の迷惑メール判定や携帯キャリアの
なりすまし規制では、エラーが返らないまま破棄されることがあります。

「署名」タブでは複数の署名を登録・編集・削除できます。作成・送信画面で署名を
選択すると、送信時に本文末尾へ自動追加されます。テンプレートとは別管理なので、
同じ本文でも担当者や部署に合わせて署名を切り替えられます。

「連絡先」タブでは、上司・部下など送信のたびによく使う相手の名前とメール
アドレスを登録しておけます。「3. 宛先設定」の固定CC・固定BCC欄の
「連絡先から追加」ボタンから、登録した相手をチェックボックスで選んで
追記できます。「Excelからインポート」からは、
Excel / CSVの任意の列を「名前」「メールアドレス」として選び、まとめて
連絡先登録できます。既存と同じ名前があれば、上書き前に確認します。

データプレビューでは任意の列を選び、「含む」「完全一致」「空欄」
「空欄でない」で絞り込めます。画面に表示された絞り込み結果だけが一括送信の
対象となり、対象件数はプレビュー上部に表示されます。

一番左の「状態（送信対象）」列のチェックを外すと、その行はプレビューに
表示されたまま送信対象からだけ除外できます。見出しをクリックすると全行の
チェックを一括で切り替えられます。チェック状態は名簿の保存・再読み込みには
保持されず、開き直すと全行チェック済みに戻ります。

## 迷惑メール判定を減らすために

アプリは1通ずつ2秒以上の間隔で送信し、重複宛先・不正アドレスを送信前に
検査します。エラー行の手動有効化は、内容を確認して問題がない場合に限って
使用してください。Microsoft 365管理者は、送信ドメインのSPF・DKIM・DMARCをすべて
設定してください。不達アドレスは名簿から削除し、広告やニュースレターなどの
大量配信にはMicrosoft 365ではなく専用配信サービスの利用を推奨します。

## アップデート

インストール済みアプリは起動時にGitHub Releasesを確認します。新しい正式版が
ある場合は画面上部に通知され、「ダウンロード」から更新用インストーラーを取得し、
「今すぐ更新」でアプリの終了・更新・再起動を行えます。更新確認に失敗しても
通常機能には影響しません。

GitHub Actionsの「CI」はmainへのpushとPull Requestでテストを実行します。
「Release」は`v*`タグまたは手動実行でWindows版インストーラーを作成し、
GitHub Releaseへ添付します。自動更新には、このReleaseが添付する
`SashikomiMail-Setup-vX.Y.Z.exe`を使用します。

テスト合格後、`dist\SashikomiMail\SashikomiMail.exe` を含む配布フォルダが
作成されます。Inno Setupを導入している場合は `installer/setup.iss` を
コンパイルすると、デスクトップショートカット付きインストーラーを作成できます。

保存名簿、送信履歴の宛先・件名・エラー内容、テスト送信先はWindows DPAPIで
暗号化されます。送信履歴は初期設定で365日保持され、設定画面から期間を変更
できます。履歴画面では個別削除と、エラー・未送信対象の再送ができます。

## データ保存先

```text
%APPDATA%\SashikomiMail\sashikomi_mail.db
%APPDATA%\SashikomiMail\token_cache.bin
%APPDATA%\SashikomiMail\sashikomi_mail.log
```

名簿や送信履歴の個人情報はWindows DPAPIで暗号化されます。バックアップは原則として
保存時と同じWindowsユーザー・PCで利用してください。
